# Amharic checkout copy review

The checkout is prepared to render Amharic with the existing site typography stack: `Noto Sans Ethiopic`, then `Inter`, then the system sans-serif fallback. The HTML language remains `en` while the approved copy is English.

Do not translate or publish checkout text from this prototype without founder approval. The following customer-facing strings need an approved Amharic translation before an Amharic-first launch:

- Checkout title and opening description.
- Payment method names and transfer instructions.
- The QA notice and recipient/account labels.
- Payment claim, pending review, payment confirmed, and download-ready status messages.
- Private recovery-code instructions, warnings, and failure messages.
- Button labels, order recovery help, and Telegram support label.

Keep meaning and payment-status distinctions intact: a submitted transaction reference is a claim, never confirmation; only a founder's independent approval can set payment confirmed and make downloads ready.
